# Эдинбург и Лондон по дням

Офлайн-карта поездки 29 октября – 8 ноября 2026: маршрут по дням, подложка OpenStreetMap, пешие маршруты по улицам, места «на выбор» и находки рядом.

**Открыть:** https://sympathyys.github.io/l-o-n-d-o-n/

На iPhone: Safari → «Поделиться» → «На экран „Домой“», затем один раз открыть с иконки при интернете и дождаться надписи «Готово: карта работает без интернета». Дальше карта открывается без сети. Правки плана сохраняются на устройстве.
